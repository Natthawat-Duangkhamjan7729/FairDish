# FairDish

เว็บแอปหารบิลค่าอาหาร — คิดจากเมนูที่แต่ละคนกินจริง ไม่ใช่หารเท่ากันทั้งโต๊ะ

## ฟีเจอร์

- เพิ่ม/แก้/ลบสมาชิกในโต๊ะ พร้อมปุ่มเลิกทำ
- ใส่เมนูและราคา มีเมนูแนะนำกว่า 1,000 รายการ และจำเมนูที่เคยสั่งพร้อมราคาครั้งก่อน
- เลือกได้ว่าใครกินเมนูไหน ระบบหารเฉพาะคนที่เลือก
- ค่าบริการ / VAT คิดเป็นเปอร์เซ็นต์ และค่าส่วนกลางที่หารเท่ากันทุกคน
- กระจายเศษสตางค์ให้ยอดรายคนรวมกันเท่ากับยอดบิลพอดีเสมอ
- คัดลอกสรุปยอดส่งเข้าแชทกลุ่มได้ในปุ่มเดียว

## การใช้งาน

เป็นไฟล์ HTML ไฟล์เดียว ไม่มี build step เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย
หรือเปิดผ่าน GitHub Pages โดยตั้ง Source เป็น branch นี้ที่ root

ข้อมูลบิลถูกบันทึกไว้ใน localStorage ของเครื่องผู้ใช้เท่านั้น ไม่มีการส่งข้อมูลออกนอกเครื่อง
