# FairDish

เว็บแอปหารบิลค่าอาหาร — คิดจากเมนูที่แต่ละคนกินจริง ไม่ใช่หารเท่ากันทั้งโต๊ะ

## ฟีเจอร์

- เพิ่ม/แก้/ลบสมาชิกในโต๊ะ พร้อมปุ่มเลิกทำ
- ใส่เมนูและราคา มีเมนูแนะนำกว่า 1,000 รายการ และจำเมนูที่เคยสั่งพร้อมราคาครั้งก่อน
- เลือกได้ว่าใครกินเมนูไหน ระบบหารเฉพาะคนที่เลือก
- ค่าบริการ / VAT คิดเป็นเปอร์เซ็นต์ และค่าส่วนกลางที่หารเท่ากันทุกคน
- กระจายเศษสตางค์ให้ยอดรายคนรวมกันเท่ากับยอดบิลพอดีเสมอ
- คัดลอกสรุปยอดส่งเข้าแชทกลุ่มได้ในปุ่มเดียว
- **กลุ่มผ่านลิงก์ (v2.0)** — สร้างกลุ่ม ส่งลิงก์เข้าแชต เพื่อนกดลิงก์แล้วดูและแก้บิลเดียวกันได้ ไม่ต้องสมัครสมาชิก
  เลือกได้ว่า "ฉันคือใคร" เพื่อไฮไลต์ยอดของตัวเอง
- **หน้าตาแบบแอป (v2.1)** — มือถือมีแท็บล่าง แบ่งการกรอกเป็นแท็บ คน · เมนู · ส่วนกลาง
  และมีแถบยอดรวมติดล่างจอ ส่วนจอคอมแสดงใบสรุปค้างไว้ด้านขวา
- **หน้าแรกแบบแอป (v2.2)** — แท็บล่างมี 5 ปุ่ม (หน้าแรก / หารบิล / สรุป / กลุ่ม / อื่น ๆ)
  หน้าแรกมีปุ่มใหญ่ "เริ่มหารบิลเลย" กับ "สร้างกลุ่มก่อน" และรายการ "ทำต่อ" สำหรับบิลที่ค้างไว้
- **โหมดมืด (v2.1)** — ตามการตั้งค่าของเครื่อง หรือเลือกเองในหน้า "อื่น ๆ"

## การใช้งาน

เว็บ static ไม่มี build step ดับเบิลคลิกเปิด `index.html` ด้วยเบราว์เซอร์ได้เลย

```
index.html        โครงหน้า
css/style.css     สไตล์ทั้งหมด
js/               โค้ดแยกตามหน้าที่ (ดูรายละเอียดใน CLAUDE.md)
supabase/         SQL ของฐานข้อมูลระบบกลุ่ม
tests/            ทดสอบ — รันด้วย `node --test`
```

บิลส่วนตัวถูกบันทึกไว้ใน localStorage ของเครื่องผู้ใช้เท่านั้น
บิลกลุ่มถูกเก็บบน Supabase และใครที่มีลิงก์กลุ่มก็ดูและแก้ได้

## เปิดระบบกลุ่ม (Supabase)

ถ้ายังไม่ตั้งค่า แอปใช้งานได้ตามปกติ แค่ปิดเมนูกลุ่มไว้

1. สร้างโปรเจกต์ฟรีที่ [supabase.com](https://supabase.com)
2. เปิด **SQL Editor** วางเนื้อหาไฟล์ `supabase/schema.sql` แล้วกด Run
3. ที่ **Project Settings → API** คัดลอก Project URL และ anon key (หรือ publishable key)
   ใส่ใน `js/config.js` แล้ว push — ทั้งสองค่าเป็นค่าสาธารณะ ใส่ในหน้าเว็บได้
   ตาราง `groups` ถูกปิดไม่ให้อ่านตรง ๆ เข้าถึงได้ผ่านฟังก์ชันที่ต้องรู้รหัสกลุ่มเท่านั้น

FairDish v2.2 · ผลงานกลุ่ม คณะมนุษยศาสตร์และสังคมศาสตร์ มหาวิทยาลัยขอนแก่น

## Deploy บน Vercel

โปรเจกต์เป็น static site ไม่มี build step มี `vercel.json` กำหนดค่าไว้แล้ว

**วิธีที่ 1 — import จาก GitHub**
1. เข้า vercel.com/new แล้วเลือก repo `FairDish`
2. ที่ Framework Preset เลือก **Other**
3. กด Deploy (ไม่ต้องตั้ง build command หรือ output directory เพิ่ม)

**วิธีที่ 2 — deploy จากเครื่องตัวเอง**
```
npm i -g vercel
vercel login
vercel --prod
```
