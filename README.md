# FairDish

เว็บแอปหารบิลค่าอาหาร — คิดจากเมนูที่แต่ละคนกินจริง ไม่ใช่หารเท่ากันทั้งโต๊ะ

## ฟีเจอร์

- เพิ่ม/แก้/ลบสมาชิกในโต๊ะ พร้อมปุ่มเลิกทำ
- ใส่เมนูและราคา มีเมนูแนะนำกว่า 1,200 รายการ (ภาษาอังกฤษก็มีชื่อเมนูอังกฤษ) และจำเมนูที่เคยสั่งพร้อมราคาครั้งก่อน
- เลือกได้ว่าใครกินเมนูไหน ระบบหารเฉพาะคนที่เลือก
- ค่าบริการ / VAT คิดเป็นเปอร์เซ็นต์ และค่าส่วนกลางที่หารเท่ากันทุกคน
- กระจายเศษสตางค์ให้ยอดรายคนรวมกันเท่ากับยอดบิลพอดีเสมอ
- คัดลอกสรุปยอดส่งเข้าแชทกลุ่มได้ในปุ่มเดียว
- **กลุ่มผ่านลิงก์ (v2.0)** — สร้างกลุ่ม ส่งลิงก์เข้าแชต เพื่อนกดลิงก์แล้วดูและแก้บิลเดียวกันได้ ไม่ต้องสมัครสมาชิก
  เลือกได้ว่า "ฉันคือใคร" เพื่อไฮไลต์ยอดของตัวเอง
- **หน้าตาแบบแอป (v2.1)** — มือถือมีแท็บล่าง แบ่งการกรอกเป็นแท็บ คน · เมนู · ส่วนกลาง
  และมีแถบยอดรวมติดล่างจอ ส่วนจอคอมแสดงใบสรุปค้างไว้ด้านขวา
- **หน้าแรกแบบแอป (v2.2)** — แท็บล่างมี 5 ปุ่ม (หน้าแรก / หารบิล / สรุป / กลุ่ม / อื่น ๆ)
  หน้าแรกมีปุ่มใหญ่ "เริ่มหารบิลเลย" กับ "สร้างกลุ่มก่อน" และรายการ "ทำต่อ" สำหรับบิลที่ค้างไว้
- **v4.15 Developer Beta** — เมนูแนะนำเพิ่มเป็นกว่า 1,280 รายการ (อาหารเหนือ/ใต้ ญี่ปุ่น เกาหลี จีน ฝรั่ง คาเฟ่ ของหวาน) และกด EN แล้วเมนูแนะนำ ค่าส่วนกลาง ค่าใช้จ่ายทริป เป็นภาษาอังกฤษ (พิมพ์ไทยก็ยังค้นเจอ)
- **v4.14 Developer Beta** — เปิดในแอป LINE / IG / Facebook / Messenger / TikTok = หน้าต่างเด้ง "เปิดในเบราว์เซอร์ดีกว่า" (ครั้งเดียวต่อการเปิดแอป) แทนแถบด้านบน ปุ่มเปิดพาไปลิงก์กลุ่มที่สแกนมาด้วย
- **v4.13.2 Developer Beta** — มือถือ: รายการเมนูแนะนำสูงไม่เกิน ~3 แถว (เลื่อนในกล่อง) พิมพ์ชื่อเมนูตอนแป้นพิมพ์เปิดแล้วยังเห็นช่องที่พิมพ์
- **v4.13.1 Developer Beta** — แก้บั๊กบิลกลุ่ม: สองคนแก้พร้อมกัน รายการของคนที่บันทึกทีหลังไม่หายแล้ว (รวมข้อมูลให้เอง) + รหัสรายการไม่ซ้ำข้ามเครื่อง
- **v4.13 Developer Beta** — สแกน QR เข้ากลุ่มในแอปได้ทุกมือถือ (รวม iPhone) เป็นหน้าต่างกล้องหลังพร้อมกรอบสแกน
  ใช้ตัวอ่านในเบราว์เซอร์ถ้ามี ไม่งั้นโหลด jsQR (js/vendor/ Apache-2.0) ตอนเปิดกล้องครั้งแรก · ไม่มีกล้อง = วางลิงก์
- **v4.12 Developer Beta** — แก้ตามรายการรอบสอง:
  · หน้าถามชื่อ/หน้าต่างเข้าร่วมกลุ่มไม่เปิดแป้นพิมพ์เอง ให้แตะช่องเอง
  · สแกนเข้ากลุ่ม: เครื่องที่มีกล้องเปิดกล้องหลังทันที (เบราว์เซอร์ที่อ่าน QR ได้) · ไม่มีกล้อง (PC) = "เข้ากลุ่มด้วยลิงก์" วางลิงก์อย่างเดียว
  · มือถือ: เอาแท็บ "สรุป" ออก (ซ้ำกับใบสรุปยอด) — ใครจ่าย/ใครโอนให้ใคร/ติ๊กโอน อยู่ในใบสรุปยอด กดจากแถบล่าง
  · เปิดในแอป LINE / IG / Messenger / Facebook / TikTok → แถบแนะนำเปิดในเบราว์เซอร์ (LINE กดเปิดให้เลย)
  · เริ่มทริป / ทริปแบบกลุ่ม ตั้งชื่อได้ (ไม่บังคับ) · ทุกคนติ๊กโอนครบ → ทุกเครื่องในกลุ่มขึ้นหน้าจบทริป/จบมื้อเอง
- **v4.11 Developer Beta** — แก้บั๊กตามรายการ:
  · คนสร้างกลุ่ม **ยุบกลุ่ม**ได้ (ลบบนเซิร์ฟเวอร์ เก็บสำเนาไว้ในประวัติ) — ต้องรัน `supabase/schema.sql` ใหม่ใน Supabase
  · ปุ่ม **สแกนเข้ากลุ่ม** ข้าง "วันนี้หารอะไร" (สแกน QR ในแอปบนเบราว์เซอร์ที่รองรับ / วางลิงก์ / ใช้แอปกล้อง)
  · **เข้ารหัสบิลกลุ่ม** (AES-GCM) ก่อนส่งขึ้นเซิร์ฟเวอร์ กุญแจอยู่ในลิงก์หลัง # เท่านั้น ฐานข้อมูลหลุดก็อ่านไม่ได้ (กลุ่มเก่ายังเปิดได้)
  · ชวนเพื่อนเป็น **หน้าต่าง** ทั้งมือถือและจอใหญ่ และเอาออกจากแถบซ้าย · QR รองรับถึงเวอร์ชัน 15 (ลิงก์ยาวขึ้นจากกุญแจ)
  · แก้ช่องวางลิงก์เข้ากลุ่มในหน้าประวัติที่พังตั้งแต่ v4.9 (ชื่อฟังก์ชันซ้ำ) + test กันชื่อซ้ำ
- **v4.10.1 Developer Beta** — เข้าแอปครั้งแรกจาก QR/ลิงก์กลุ่ม (ถามชื่อ → ถามเข้าร่วม) แล้วกดกลับ ไปหน้าหลักเลย ไม่เจอหน้าแนะนำแอปซ้ำ
  (ดูได้ที่ ตั้งค่า → ดูหน้าแนะนำอีกครั้ง)
- **v4.10 Developer Beta** — หน้าหลักขึ้นการ์ดความคืบหน้าของบิลกลุ่ม/ทริปแบบกลุ่มที่ยังไม่จบด้วย (เปิดใน 30 วัน สูงสุด 3 ใบ)
  บิลที่โอนครบแล้วป้ายเป็น "เสร็จแล้ว" และขึ้นด้านบนแค่ครั้งแรกที่เห็น — ครั้งต่อไปบิลในเครื่องเก็บเข้าประวัติ บิลกลุ่มลงไปอยู่ "บิลล่าสุด"
- **v4.9 Developer Beta** — สแกน QR เข้ากลุ่มครั้งแรก: ถามชื่อก่อน (หน้าเต็ม ไม่ผ่านหน้าแนะนำ) แล้วพากลับหน้ากลุ่มพร้อมถาม
  "เข้าร่วมกลุ่ม X ไหม?" ปุ่มเดียว "เข้าร่วมในชื่อ …" (มีชื่อในกลุ่มอยู่แล้วเลือกได้ / ชื่อตรงกันเลือกให้เอง)
  ลิงก์ยืนยันเมนูของมื้ออาหารก็มีปุ่ม "เข้าร่วมในชื่อ …" / "ฉันคือ …"
- **v4.8.2 Developer Beta** — ใส่แค่ชื่อคนแล้วกดกลับ หน้าหลักขึ้นการ์ด "กำลังหาร" ให้ทำต่อได้ (เดิมต้องมีเมนูก่อนถึงจะขึ้น)
  และเริ่มบิลใหม่แล้วบิลที่มีแค่ชื่อถูกเก็บเข้าประวัติ ไม่ถูกทับทิ้ง
- **v4.8.1 Developer Beta** — ปุ่มย้อนกลับในหน้าชวนเพื่อนกลับไปหน้าที่กดแชร์มา (หน้าหารบิล → แชร์ → ย้อนกลับ = หน้าหารบิล)
  เดิมพาไปใบสรุปยอดเสมอ ซึ่งในทริปที่เพิ่งสร้างยังว่าง
- **v4.8 Developer Beta** — มื้ออาหาร: ใส่ชื่อเพื่อนกับเมนูในเครื่องก่อน ปุ่ม "ชวนเพื่อนตรวจยอด · ยืนยันเมนู" อยู่ท้ายใบสรุปยอด
  (เอาออกจากแถบซ้ายและตอนบิลยังว่าง) · ทริป: เลือก "ทริปแบบกลุ่ม" ตอนเริ่ม หรือกด "สร้างกลุ่มทริป" ในขั้นใส่คน
  สร้างกลุ่มก่อน ลิงก์/QR พาเพื่อนเข้าบิลทริปเดียวกันให้ใส่ค่าใช้จ่ายเองได้ตลอดทริป
- **v4.7 Developer Beta** — หน้าชวนเพื่อน / หารบิล / ใบสรุปของกลุ่มอัปเดตเองทุก 3 วินาที เพื่อนเข้ากลุ่มหรือยืนยันเมนูแล้วขึ้นทันที
  พร้อมแจ้งว่า "X เข้ากลุ่มแล้ว" (ไม่วาดทับตอนกำลังพิมพ์) · สร้างกลุ่มแล้วใส่ชื่อคนสร้าง (คนเปิด QR) ในบิลให้เลย
  และจำว่า "ฉันคือคนนี้" ยังไม่มีชื่อ = ถามชื่อก่อนกดสร้างกลุ่ม
- **v4.6 Developer Beta** — ถาม "อยากให้เราเรียกคุณว่าอะไรดี?" ตอนใช้งานครั้งแรก (ต่อจากหน้าแนะนำ กด "ไว้ทีหลัง" ได้)
  เปลี่ยนหรือลบชื่อได้ตลอดที่ ตั้งค่า → ชื่อที่ให้เราเรียก · หน้าหลักทักทายด้วยชื่อ · ขั้นใส่คนมีปุ่ม "+ เพิ่มตัวเอง"
  · เปิดกลุ่มที่มีชื่อตรงกัน เลือก "ฉันคือใคร" ให้เอง · ชื่อเก็บในเครื่องเท่านั้น ไม่ไปกับบิลหรือกลุ่ม
- **v4.5.3 Developer Beta** — ธีมเลือกได้ 3 แบบ ตามระบบ / มืด / สว่าง (ยังไม่เคยเลือก = สว่าง)
  และปุ่มชวนเพื่อนสร้างกลุ่มได้ทันทีแม้บิลยังว่างหรือยังไม่ได้เปิดบิล
- **v4.5.2 Developer Beta** — เปิดมาเป็นโหมดสว่างเสมอ (ไม่ตามเครื่อง) เปิดโหมดมืดด้วยสวิตช์ในตั้งค่า
  และ "สอนใช้แบบกดจริง" เริ่มจากขั้นแรกด้วยบิลฝึกว่าง ๆ เสมอ แม้มีบิลที่ทำค้างไว้
- **v4.5.1 Developer Beta** — ทุกขั้นของการสอนมีปุ่ม "ถัดไป" ไม่อยากกรอกก็กดได้ ระบบใส่ตัวอย่างให้ดูแล้วไปขั้นต่อไป
- **สอนใช้แบบกดจริง (v4.5 Developer Beta)** — ต่อจากหน้าแนะนำ (กด "เริ่มใช้งาน") ไฮไลต์ปุ่มที่ต้องกดทีละขั้นด้วย "บิลฝึก"
  (ใส่ชื่อ → เพิ่มเมนู → เลือกคนกิน → ค่าบริการ → ใครจ่าย → ติ๊กโอนแล้ว → ส่งเข้ากลุ่ม) บิลฝึกไม่ถูกบันทึก บิลจริงไม่ถูกแตะ
  จบแล้วถามติดตั้งแอป (มือถือ/แท็บเล็ต แสดงวิธีของ iOS หรือ Android ทันที) หรือไปหน้าหลัก · เปิดซ้ำได้ที่ ตั้งค่า → สอนใช้แบบกดจริง
- **v4.4.1 Developer Beta** — ทุกคนเห็นหน้าแนะนำแบบใหม่หนึ่งครั้ง (เปิดครั้งแรกจากลิงก์หน้าไหนก็ขึ้น ยกเว้นลิงก์กลุ่มจากเพื่อน)
  และช่องเพิ่มรายการบรรทัดเดียวบนจอใหญ่มีเมนูแนะนำ (เมนูที่เคยสั่งพร้อมราคา / คลังเมนู / ค่าใช้จ่ายทริป)
- **แท็บเล็ตและคอมตามดีไซน์ FairDish Wide (v4.4 Developer Beta)** — มือถือเหมือนเดิม
  - แถบนำทางซ้าย (แท็บเล็ตเป็นแถบไอคอน คอมเป็นแถบเต็มพร้อมเคล็ดลับ) และหน้าแนะนำแบบหน้าเดียวมีน้องหอยทาก
  - **หน้าหารบิลแบบพื้นที่ทำงาน** คน | รายการ | สรุปยอดสด — แตะชื่อบนการ์ดได้เลย, ลากชื่อไปวางบนรายการ, แตะคนเพื่อดูเฉพาะรายการของเขา,
    เพิ่มรายการในบรรทัดเดียว (กด N), เลิกทำ (Ctrl/⌘+Z)
  - หน้าแรกมีการ์ดเริ่มบิล (กด M / T), ใบสรุปยอดมีใครจ่าย + ใครโอนให้ใครข้างใบเสร็จ, หน้าชวนเพื่อนแสดงตัวอย่างหน้าที่เพื่อนเห็น,
    ประวัติแบบรายการ + รายละเอียด ค้นหาและกรองตามประเภทได้
- **ใช้ได้ทุกอุปกรณ์ (v4.3 Developer Beta)** — มือถือเหมือนเดิม, แท็บเล็ตขยายกว้างขึ้นและฟอร์มเป็นหน้าต่างกลางจอ,
  จอคอมมีแถบเมนูด้านซ้าย หน้าหารบิลมีแผงสรุปยอดสดด้านขวา และใบสรุปยอดวางใบเสร็จคู่กับใครโอนให้ใคร

  ไว้ในบิลกลุ่มบนเซิร์ฟเวอร์ (ข้อมูลส่วนบุคคลตาม PDPA) ข้อมูลเบอร์ที่บันทึกไปแล้วถูกล้างเมื่อบิลถูกบันทึกครั้งถัดไป

  - **หน้าชวนเพื่อนเข้ากลุ่ม** QR + ลิงก์ + สถานะ ยืนยันแล้ว / รอยืนยัน ของทุกคน
  - **เพื่อนยืนยันเมนูเอง** เปิดลิงก์ เลือกชื่อ ติ๊กเมนูที่กิน เห็นยอดของตัวเองก่อนกดยืนยัน (ชนกับคนอื่นก็รวมให้เอง — ตรรกะจาก v4.0)

  - กดเริ่มบิลใหม่ (หรือปุ่ม + ตรงกลางแท็บล่าง) เลือก 🍲 มื้ออาหาร / ✈️ ทริป ครั้งเดียว บิลเดิมย้ายเข้า **ประวัติบิล** ให้เอง เปิดกลับมาทำต่อได้
  - หน้าหารบิลมีแท็บด้านบน คน / เมนู / ส่วนกลาง / สรุป, เพิ่ม-แก้รายการผ่านแผ่นล่างจอ และแถบยอดรวมติดล่างจอ
  - แท็บสรุปเลือกคนจ่ายให้ร้านได้ทันที แล้ว **ติ๊กว่าโอนแล้ว** ทีละรายการ (ในกลุ่มทุกคนเห็นตรงกัน) ติ๊กครบขึ้นหน้า "จบมื้อแล้ว 🎉"
  - ใบสรุปยอดมีปุ่ม "ชวนเพื่อนเข้ากลุ่ม" ย้ายบิลส่วนตัวขึ้นกลุ่มแล้วเปิด QR ให้เลย
  - จอคอมใช้หน้าตาเดียวกับมือถือ จัดไว้กลางจอ · โหมดมืดยังใช้ได้
- **มื้ออาหารข้างในทริป (v3.1 Developer Beta)** — ในทริปกด "+ มื้ออาหาร 🍲" แล้วใส่เมนูหารตามที่กินจริงได้เหมือนโหมดอาหาร
  (มีค่าบริการ/VAT ของมื้อนั้น) ระบุคนจ่ายมื้อ แล้วทั้งทริปสรุปการโอนครั้งเดียว
- **หารได้ทุกอย่าง: โหมดทริป (v3.0 Developer Beta)** — เลือกประเภทตอนเริ่ม 🍲 มื้ออาหาร / ✈️ ทริป
  ทริประบุคนจ่ายในแต่ละรายการ (ที่พัก ค่าน้ำมัน ตั๋ว) แล้วสรุปว่าใครโอนให้ใคร ไม่มีค่าบริการ/VAT และมีรายการแนะนำของทริป
- **ชวนเพื่อนด้วย QR (v2.7)** — ปุ่ม "ชวนเพื่อน" ในกลุ่มเปิดหน้าต่างที่มี QR code (โลโก้แอปตรงกลาง)
  แชร์ผ่านแอปอื่น, คัดลอกลิงก์พร้อมคำชวน และบันทึกรูป QR — สร้าง QR เองใน `js/qr.js` ไม่ใช้ไลบรารี
- **จัดหน้าให้โล่ง (v2.6)** — แตะชื่อหรือแถวเมนูเพื่อแก้/ลบ (ไม่มีไอคอนในแถว), รายชื่อคนกินแบบสั้น,
  ส่วนที่ใช้น้อยพับไว้ (ใครจ่าย, วางลิงก์กลุ่ม), กรอบแอปบนมือถือบางลง
- **ใครโอนให้ใคร (v2.5)** — ในหน้าสรุปเลือกได้ว่าใครจ่ายให้ร้านไปก่อน (หลายคนก็ได้ เว้นยอดไว้ได้หนึ่งคนเป็นส่วนที่เหลือ)
  แล้ว FairDish หักลบให้เหลือการโอนน้อยครั้งที่สุด แสดงในหน้าสรุป ข้อความที่คัดลอก และรูปใบเสร็จ
- **ออกแบบตามจิตวิทยาผู้ใช้ (v2.4)**
  - เข้ากลุ่มครั้งแรกถาม "คุณคือใคร" แล้วแสดง "ยอดของคุณ" ตัวใหญ่
  - หารบิลเสร็จมีหน้า "จบมื้อแล้ว! 🎉" แชร์เป็นรูปใบเสร็จได้ และข้อความที่คัดลอกเปิดด้วยคำขอบคุณ
  - เพิ่มเมนูใหม่เลือกไว้ "ทุกคน" ตั้งแต่แรก, กลุ่มใหม่มีชื่อตั้งต้น เช่น "มื้อ 4 ต.ค."
  - ปุ่มลบเป็นแบบเส้นขอบไม่ปนกับปุ่มหลัก, ล้างบิลกลุ่มต้องพิมพ์ชื่อกลุ่ม และล้างแล้วกดเลิกทำได้
  - ชวนติดตั้งแอปตอนหารบิลเสร็จ (มือถือ) กดปิดแล้วไม่ชวนอีก
- **ติดตั้งเป็นแอป (v2.3)** — ปุ่ม "ติดตั้งแอป" มุมขวาบน (มือถือเท่านั้น) ตรวจระบบให้เองแล้วแสดงเฉพาะวิธีของ iOS หรือ Android
  Chrome บน Android กดติดตั้งได้ในปุ่มเดียว และเตือนถ้าเปิดอยู่ใน LINE / Facebook / Instagram ซึ่งติดตั้งไม่ได้
- **โหมดมืด (v2.1)** — ตามการตั้งค่าของเครื่อง หรือเลือกเองในหน้า "อื่น ๆ"

## การใช้งาน

เว็บ static ไม่มี build step ดับเบิลคลิกเปิด `index.html` ด้วยเบราว์เซอร์ได้เลย

```
index.html        โครงหน้า
css/style.css     สไตล์ทั้งหมด
js/               โค้ดแยกตามหน้าที่ (ดูรายละเอียดใน CLAUDE.md)
supabase/         SQL ของฐานข้อมูลระบบกลุ่ม
tests/            ทดสอบ — รันด้วย `node --test`
```

บิลส่วนตัวถูกบันทึกไว้ใน localStorage ของเครื่องผู้ใช้เท่านั้น
บิลกลุ่มถูกเก็บบน Supabase และใครที่มีลิงก์กลุ่มก็ดูและแก้ได้

## เปิดระบบกลุ่ม (Supabase)

ถ้ายังไม่ตั้งค่า แอปใช้งานได้ตามปกติ แค่ปิดเมนูกลุ่มไว้

1. สร้างโปรเจกต์ฟรีที่ [supabase.com](https://supabase.com)
2. เปิด **SQL Editor** วางเนื้อหาไฟล์ `supabase/schema.sql` แล้วกด Run
3. ที่ **Project Settings → API** คัดลอก Project URL และ anon key (หรือ publishable key)
   ใส่ใน `js/config.js` แล้ว push — ทั้งสองค่าเป็นค่าสาธารณะ ใส่ในหน้าเว็บได้
   ตาราง `groups` ถูกปิดไม่ให้อ่านตรง ๆ เข้าถึงได้ผ่านฟังก์ชันที่ต้องรู้รหัสกลุ่มเท่านั้น

FairDish v3.1 Developer Beta · ผลงานกลุ่ม คณะมนุษยศาสตร์และสังคมศาสตร์ มหาวิทยาลัยขอนแก่น

## Deploy บน Vercel

โปรเจกต์เป็น static site ไม่มี build step มี `vercel.json` กำหนดค่าไว้แล้ว

**วิธีที่ 1 — import จาก GitHub**
1. เข้า vercel.com/new แล้วเลือก repo `FairDish`
2. ที่ Framework Preset เลือก **Other**
3. กด Deploy (ไม่ต้องตั้ง build command หรือ output directory เพิ่ม)

**วิธีที่ 2 — deploy จากเครื่องตัวเอง**
```
npm i -g vercel
vercel login
vercel --prod
```
